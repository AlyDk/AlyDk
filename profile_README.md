## What I Actually Do

I build the data layer that makes reporting possible — not just the reports themselves.

That means writing SQL against SAP HANA, designing star schemas, engineering Power Query M pipelines that are maintainable and fast, and building DAX measures that actually answer the business question. I've done this as the **sole analyst** at a distribution company, owning everything from raw SAP extracts to the executive dashboard.

- Replaced manual Excel-based workflows with automated SAP-to-Power BI pipelines
- Built a centralized M function library used across all fact tables so channel logic lives in one place and changes propagate everywhere
- Implemented Price-Volume-Mix decomposition with dynamic plain-English DAX text cards that auto-generate executive summaries based on slicer context
- Designed and shipped 6+ dashboard pages covering open orders, inventory, sell-out, sales drivers, and margin health

## Projects

### Production Work

**[Power BI Distribution Analytics](https://github.com/AlyDk/powerbi-dist-analytics)**

Built from scratch as the sole analyst at an electronics distribution company. Star schema with three fact tables fed by SAP HANA native SQL queries, a centralized Power Query M function library for channel classification, and 6 dashboard pages covering sales performance, open orders, inventory visibility, and weekly sell-out tracking. Includes a defensive W01 edge case fix that kept weekly data aligned across all tables.

`SAP HANA` `Power Query M` `DAX` `Star Schema` `ETL`

**[Sales Performance Dashboard](https://github.com/AlyDk/sales-performance-dashboard)**

Price-Volume-Mix decomposition report that separates YoY sales delta into Volume and Price/Mix contributions at category and channel level. Features auto-generated plain-English DAX summary cards, a Finance budget vs actual tracker (Excel unpivot pipeline aligned to the star schema), and a salesperson margin health monitor. Built on the same SAP HANA architecture as the distribution analytics platform.

`PVM Analysis` `DAX` `Power Query M` `Budget Tracking` `Dynamic Text`
